# kubectl命令参考手册

## 一、基础语法与常用参数

### 命令结构
```bash
kubectl [command] [type] [name] [flags]
```
- **command**：操作类型（create/get/describe/delete等）
- **type**：资源类型（pod/deployment/service等，支持单数/复数/缩写）
- **name**：资源名称（可选，省略则操作所有资源）
- **flags**：可选参数（-n指定命名空间，-o指定输出格式等）

### 常用全局参数
| 参数 | 缩写 | 说明 |
|------|------|------|
| --namespace | -n | 指定命名空间 |
| --all-namespaces | -A | 所有命名空间 |
| --output | -o | 输出格式（yaml/json/wide等） |
| --selector | -l | 按标签筛选资源 |
| --dry-run |  | 模拟操作不实际执行 |

## 二、资源管理命令

### 1. 创建资源
#### kubectl create
```bash
# 从文件创建
kubectl create -f pod.yaml
# 快速创建Deployment
kubectl create deployment nginx --image=nginx:1.24 --replicas=3
# 创建Service（ClusterIP类型）
kubectl create service clusterip my-service --tcp=8080:80
# 创建命名空间
kubectl create namespace dev
```

#### kubectl apply（推荐生产环境）
```bash
# 创建或更新资源
kubectl apply -f deployment.yaml
# 从目录批量创建
kubectl apply -f ./k8s-resources/
# 从URL创建
kubectl apply -f https://raw.githubusercontent.com/kubernetes/website/main/content/en/examples/pods/simple-pod.yaml
```

### 2. 查看资源
#### kubectl get
```bash
# 查看当前命名空间Pod
kubectl get pods
# 查看指定命名空间Deployment
kubectl get deploy -n kube-system
# 查看Service详细信息（含IP和端口）
kubectl get svc -o wide
# 按标签筛选Pod
kubectl get pods -l app=nginx
# 查看资源YAML定义
kubectl get pod my-pod -o yaml
```

#### kubectl describe
```bash
# 查看Pod详细状态（含事件和容器信息）
kubectl describe pod my-pod
# 查看节点资源使用情况
kubectl describe node node-1
# 查看Service关联的Endpoint
kubectl describe svc my-service
```

### 3. 更新资源
#### kubectl set
```bash
# 更新Deployment镜像
kubectl set image deployment/nginx nginx=nginx:1.25
# 修改资源限制
kubectl set resources deployment/nginx --limits=cpu=200m,memory=256Mi
```

#### kubectl patch
```bash
# 部分更新节点（标记为不可调度）
kubectl patch node node-1 -p '{"spec":{"unschedulable":true}}'
# 更新容器镜像（JSON格式）
kubectl patch pod my-pod --type=json -p='[{"op":"replace","path":"/spec/containers/0/image","value":"nginx:1.25"}]'
```

### 4. 删除资源
```bash
# 删除Pod
kubectl delete pod my-pod
# 删除Deployment及其管理的Pod
kubectl delete deploy my-deploy
# 从文件删除资源
kubectl delete -f pod.yaml
# 按标签批量删除
kubectl delete pods -l app=old
# 强制删除无响应Pod
kubectl delete pod my-pod --grace-period=0 --force
```

## 三、集群管理命令

### 1. 节点管理
```bash
# 查看节点状态
kubectl get nodes
# 标记节点不可调度
kubectl cordon node-1
# 排空节点（维护前准备）
kubectl drain node-1 --ignore-daemonsets
# 恢复节点调度
kubectl uncordon node-1
# 添加节点污点
kubectl taint nodes node-1 key=value:NoSchedule
```

### 2. 命名空间与上下文
```bash
# 查看所有命名空间
kubectl get ns
# 切换默认命名空间
kubectl config set-context --current --namespace=dev
# 查看当前上下文
kubectl config current-context
# 切换集群上下文
kubectl config use-context prod-cluster
```

### 3. 资源配额与限制
```bash
# 创建资源配额
kubectl create quota my-quota --hard=cpu=2,memory=4Gi,pods=10
# 查看配额使用情况
kubectl describe quota my-quota
```

## 四、故障排查命令

### 1. 日志与监控
```bash
# 查看Pod日志
kubectl logs my-pod
# 查看容器日志（多容器Pod）
kubectl logs my-pod -c app-container
# 实时查看日志
kubectl logs my-pod -f
# 查看前100行日志
kubectl logs my-pod --tail=100
# 查看指定时间段日志
kubectl logs my-pod --since=1h
```

### 2. 容器交互
```bash
# 进入容器终端
kubectl exec -it my-pod -- /bin/bash
# 执行单条命令
kubectl exec my-pod -- ls /app
# 端口转发（本地8080映射到Pod 80）
kubectl port-forward my-pod 8080:80
```

### 3. 集群诊断
```bash
# 查看集群信息
kubectl cluster-info
# 检查组件健康状态
kubectl get cs
# 查看节点资源使用
kubectl top nodes
# 查看Pod资源使用
kubectl top pod my-pod
# 导出集群事件
kubectl get events --sort-by=.metadata.creationTimestamp
```

## 五、高级操作命令

### 1. 滚动更新与回滚
```bash
# 查看Deployment历史版本
kubectl rollout history deployment/nginx
# 回滚到上一版本
kubectl rollout undo deployment/nginx
# 回滚到指定版本
kubectl rollout undo deployment/nginx --to-revision=2
# 暂停更新
kubectl rollout pause deployment/nginx
# 恢复更新
kubectl rollout resume deployment/nginx
```

### 2. 自动扩缩容
```bash
# 创建HPA（CPU使用率>80%时扩容）
kubectl autoscale deployment nginx --min=2 --max=10 --cpu-percent=80
# 手动扩缩容
kubectl scale deployment nginx --replicas=5
```

### 3. 配置管理
```bash
# 创建ConfigMap
kubectl create configmap app-config --from-literal=env=prod --from-file=app.conf
# 创建Secret
kubectl create secret generic db-secret --from-literal=password=123456
# 查看ConfigMap内容
kubectl get configmap app-config -o yaml
```

## 六、常用输出格式与筛选

### 1. 输出格式选项
```bash
# YAML格式
kubectl get pod my-pod -o yaml
# JSON格式
kubectl get pod my-pod -o json
# 自定义列
kubectl get pods -o custom-columns='NAME:.metadata.name,STATUS:.status.phase'
# 仅显示名称
kubectl get pods -o name
```

### 2. 数据筛选与排序
```bash
# 按重启次数排序
kubectl get pods --sort-by=.status.containerStatuses[0].restartCount
# 筛选运行中的Pod
kubectl get pods --field-selector=status.phase=Running
# 查看包含特定标签的所有资源
kubectl get all -l app=nginx
```

## 七、实用技巧与注意事项

1. **命令别名设置**：
   ```bash
   alias k=kubectl
   complete -o default -F __start_kubectl k
   ```

2. **自动补全配置**：
   ```bash
   # Bash
   source <(kubectl completion bash)
   # Zsh
   source <(kubectl completion zsh)
   ```

3. **强制删除资源**：
   ```bash
   kubectl delete pod my-pod --grace-period=0 --force
   ```

4. **资源缩写**：
   - pod (po)、deployment (deploy)、service (svc)
   - replicaset (rs)、namespace (ns)、configmap (cm)

5. **避免误操作**：
   - 删除前先执行`--dry-run=client`验证
   - 生产环境建议使用`kubectl apply`而非`create/delete`
